# livaishina

Telegram-бот учебного курса по монтажу: дедлайны, материалы, пересылка вопросов
и домашних работ админу в личку (любой формат: текст, фото, видео, файлы).

## Стек

- **aiogram 3** — полностью асинхронный
- **PostgreSQL 16** + **SQLAlchemy 2** (asyncpg)
- **Docker Compose** — бот + БД, автоперезапуск
- **GitHub Actions** — деплой на сервер при пуше в `main`

## Логика «домашек»

Никаких FSM-режимов: ученик в любой момент пишет боту или кидает файл —
сообщение копируется админу (с ID отправителя). Админ отвечает **reply'ем**
на сообщение — ответ уходит ученику. Рестарты боту не страшны.

## Запуск локально

```bash
cp config/.env.example config/.env   # вписать токен, пароль БД
docker compose up -d --build
```

## Деплой

Push в `main` → Actions → SSH на сервер → `git pull && docker compose up -d --build`.

Секреты репозитория: `SSH_HOST`, `SSH_USER`, `SSH_PRIVATE_KEY`.

## Админ-функции

- `/question` — подсказка (не обязательна)
- Reply на пересланное сообщение — ответ ученику
- Кнопка «Ученики» (видна только админу) — список пользователей
